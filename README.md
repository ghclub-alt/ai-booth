# ai-booth

**나를 닮은 AI 캐릭터** 부스입니다. 행사장 태블릿이나 PC에 띄워 두면 방문자가 얼굴 사진을 찍고, 질문에 답하면 OpenAI 이미지 모델이 7.5 × 10 cm 크기의 캐릭터 그림을 만들어 줍니다.
HTML 파일 하나로 돌아가며, 설치하거나 빌드할 것이 없습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index-claude.html` | **Claude 개선판 (권장)**. `index-secure.html`에 운영 편의·비용 보호 기능을 더했습니다(아래 [Claude 개선판에 추가된 것](#claude-개선판에-추가된-것) 참고). |
| `index-secure.html` | 보안 강화판. API 키를 탭 메모리에만 두고, 관리자 비밀번호를 기기마다 처음에 직접 정합니다. |
| `index.html` | 사이트 첫 화면. 열면 바로 `index-claude.html`로 이동합니다. |
| `index-original.html` | 기존판(예전 `index.html`). API 키를 쿠키에 저장해서 새로고침해도 남고, 처음 관리자 비밀번호(`abcde12345!@`)가 코드에 들어 있습니다. |

세 파일은 화면과 사용 흐름이 같습니다. 기존판과 보안 강화판은 키와 비밀번호를 다루는 방식이 다릅니다(아래 [두 버전의 차이](#두-버전의-차이) 참고). 아래 설명에서 `index-secure.html`에 해당하는 내용은 `index-claude.html`에도 그대로 적용됩니다.

## Claude 개선판에 추가된 것

`index-claude.html`은 `index-secure.html`을 그대로 복사한 뒤 다음을 추가했습니다.

| 기능 | 내용 |
|---|---|
| 비밀번호 대입 방지 | 관리자 비밀번호를 5번 틀리면 30초 잠깁니다. 계속 틀리면 잠금 시간이 두 배씩 늘어납니다(최대 10분). 새로고침해도 풀리지 않습니다. |
| 관리자 설정 자동 닫힘 | 관리자 설정을 연 채 2분 동안 아무것도 안 하면 설정을 저장하고 닫습니다. 스태프가 자리를 비운 사이 방문자가 설정을 바꾸지 못하게 합니다. |
| 한 사람당 생성 수 | 관리자 설정에서 1·2·3(기본)·5장 또는 제한 없음을 고릅니다. '다시 만들기' 버튼에 남은 횟수가 보이고, 다 쓰면 이미 만든 그림은 그대로 둔 채 안내만 합니다. 같은 그림을 재사용하는 경우는 세지 않습니다. |
| 전체 생성 한도 | 관리자 설정의 '만든 캐릭터' 수가 한도(50~500장, 기본은 제한 없음)에 닿으면 더 이상 API를 부르지 않습니다. 키가 새거나 예상보다 많이 쓰일 때 비용을 막아 줍니다. |
| 실수로 키 잃지 않기 | API 키가 메모리에 있을 때 새로고침·탭 닫기를 하면 한 번 확인합니다. 태블릿에서 화면을 아래로 당겨 새로고침하는 동작도 막았습니다. |
| 화면 꺼짐 방지 | 부스가 시작되면 Wake Lock으로 화면이 꺼지지 않게 합니다(https·localhost, 지원 브라우저에서만). 관리자 설정에서 상태를 볼 수 있습니다. |
| 인터넷 끊김 알림 | 연결이 끊기거나 다시 연결되면 알려 주고, 끊긴 상태에서는 API를 부르지 않고 스태프를 부르라고 안내합니다. |
| 결과 그림 길게 누르기 막기 | 결과 그림을 길게 눌러 '이미지 열기' 같은 메뉴로 부스 화면을 벗어나지 않게 했습니다. 저장은 '저장하기' 버튼으로 합니다. |

## 준비물

- 카메라가 달린 태블릿이나 PC (크롬 권장)
- 이미지 생성 권한이 있는 **OpenAI API 키**
- 인쇄하려면 프린터 (선택)
- 인터넷 연결: OpenAI API, 얼굴 인식 모델(MediaPipe, jsDelivr/Google Storage), 웹 글꼴(Google Fonts)을 불러옵니다.

## 실행 방법

브라우저는 **보안 연결(https 또는 localhost)** 에서만 실시간 카메라를 허용합니다. 다음 중 하나로 여세요.

1. **https 주소에 올리기 (권장)**
   GitHub Pages 같은 곳에 올리고 `https://…/index-claude.html`로 엽니다.
   이 저장소는 GitHub Pages(`main` 브랜치 루트)로 배포되어, 사이트 주소로 들어가면 `index.html`이 `index-claude.html`로 보내 줍니다.
2. **같은 기기에서 로컬 서버 실행**
   ```bash
   python3 -m http.server 8000
   ```
   그다음 같은 기기의 브라우저에서 `http://localhost:8000/index-claude.html`을 엽니다.
3. **http 주소를 꼭 써야 할 때 (예: `http://192.168.x.x`)**
   크롬 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`에 그 주소를 등록합니다.

> 파일을 더블클릭해서 `file://`로 열면 실시간 카메라가 막힐 수 있습니다. 이때도 '기본 카메라 앱으로 찍기' 버튼은 동작합니다.
> `index-secure.html`의 관리자 비밀번호 설정은 https나 localhost에서만 됩니다(Web Crypto 필요).

## 처음 설정 (스태프)

### `index-secure.html`

1. 페이지를 처음 열면 **관리자 비밀번호 처음 설정** 창이 뜹니다. 10자 이상으로 정하세요. 이 비밀번호는 그 기기의 브라우저에만 저장됩니다.
2. 그 뒤로는 페이지를 열 때마다 관리자 비밀번호를 넣어야 부스가 시작됩니다.
3. 관리자 설정에서 **API 키**를 넣고 '키 저장'을 누릅니다.
   - 키는 현재 탭의 메모리에만 있습니다. **새로고침하거나 탭을 닫으면 다시 넣어야 합니다.**
4. 필요하면 아래 설정을 바꾸고 '닫기'를 누릅니다. 태블릿에서는 '전체 화면'을 켜 두면 좋습니다.

### `index-original.html`

- 처음 비밀번호는 `abcde12345!@`입니다. 관리자 설정 맨 아래에서 **꼭 바꾸세요.**
- API 키는 쿠키에 저장돼서 새로고침해도 남습니다. 행사가 끝나면 'API 키 삭제'를 누르세요.

## 관리자 설정 열기

화면에 관리자 버튼은 없습니다. 맨 위 작은 글씨 **'AI 리터러시 체험 부스 ✎'** 를 이용합니다.

- **2초 동안 길게 누르기** (태블릿)
- 또는 **2초 안에 5번 빠르게 탭**
- 또는 키보드에서 **Ctrl + Shift + S**

열면 관리자 비밀번호를 묻습니다.

### 설정 항목

| 항목 | 내용 |
|---|---|
| API 키 | 넣기, 바꾸기, 삭제 |
| AI 모델 | '자동'을 권장합니다. 빠른 모델부터 차례로 시도하고, 쓸 수 없으면 다음 모델로 넘어갑니다. |
| 그림 품질 | 낮음(권장, 가장 빠르고 저렴) / 보통 / 높음 |
| 인쇄 용지 | A4 같은 일반 용지(자르는 선 표시) 또는 7.5 × 10 cm 용지(꽉 차게) |
| 사진 아래 문구 | 그림 아래에 날짜와 함께 들어갈 문구 (최대 24자) |
| 자동 초기화 | 아무 조작이 없으면 60초 / 90초 / 3분 뒤 처음 화면으로 돌아갑니다(끌 수도 있음). |
| 생성 개수 | 이 브라우저에서 만든 캐릭터 수를 보여 주고, 0으로 되돌릴 수 있습니다. |
| 관리자 비밀번호 | 비밀번호 바꾸기 |
| 전체 화면 | 전체 화면 켜기/끄기 |

## 방문자 사용 흐름

1. **시작**: 사진과 입력한 문구가 OpenAI로 전송된다는 안내를 확인하고 '시작!'을 누릅니다. 사진 없이 진행할 수도 있습니다.
2. **찰칵**: 화면의 동그라미 안에 얼굴을 맞추고 찍습니다. 얼굴 인식이 위치를 안내해 주고, 마음에 안 들면 '다시 찍기'를 누르면 됩니다.
3. **말하기**: 그림체, 표정, 옷, 포즈, 손에 든 것, 배경, 추가로 원하는 것을 고르거나 직접 씁니다.
4. **완성**: AI가 그림을 그리면 **저장하기**(JPG), **인쇄하기**, **2분 화면고정**(따라 그리는 동안 화면을 그대로 두고 터치만 막기)을 할 수 있습니다.

처음 화면으로 돌아가면 사진과 생성된 그림을 메모리에서 지웁니다.

## 인쇄 팁

- 그림 크기는 항상 **7.5 × 10 cm**(750 × 1000 px)입니다.
- 프린터 창의 배율은 **기본값(100%)** 으로 두어야 실제 크기로 나옵니다.

## 두 버전의 차이

| | `index-secure.html` | `index-original.html` |
|---|---|---|
| API 키 저장 | 탭 메모리만 (새로고침하면 삭제) | 쿠키 (`file://`로 열면 localStorage) |
| 관리자 비밀번호 | 처음 실행할 때 직접 설정 (10자 이상), PBKDF2 해시로 저장 | 기본값 `abcde12345!@`, 바꾸면 해시로 저장 |
| 예전 키 정리 | 남아 있는 평문 쿠키·localStorage 키를 자동 삭제 | – |
| 리퍼러 차단 | `no-referrer` | – |

## 보안 주의사항

- 이 페이지는 **브라우저에서 OpenAI API를 직접 호출**합니다. 그래서 개발자 도구(Network 탭)를 열면 API 키가 보일 수 있습니다. 백엔드 없이는 막을 수 없습니다.
- 관리자 비밀번호는 방문자가 설정을 건드리지 못하게 하는 **화면 잠금일 뿐**이고, 서버 인증을 대신하지 않습니다.
- 따라서 **스태프가 지키는 행사 기기에서만** 쓰고, 행사가 끝나면 API 키를 삭제하세요.
- OpenAI 대시보드에서 **사용량 한도(예산)** 를 걸어 두고 모니터링하세요.
- 공개 웹사이트로 서비스하려면 API 키를 서버(백엔드 프록시)에만 두는 구조로 바꿔야 합니다.
- `index-original.html`은 비밀번호를 잊으면 브라우저에서 이 사이트의 데이터를 지워 초기화합니다(API 키와 설정도 같이 지워짐). `index-secure.html`도 사이트 데이터를 지우면 처음 설정 화면으로 돌아갑니다.
